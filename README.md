# 賞状メーカー

表彰者リストのCSVと賞状台紙のスキャン画像から、賞状の印刷用PDFを作るWebアプリです。
処理はすべてブラウザ内で行います。CSVや台紙の画像がサーバーへ送られることはありません。

## 使い方

画面右側のタブを ① から順に進めます。

| 手順 | 内容 |
|---|---|
| ① 台紙 | 賞状台紙のスキャン画像（JPG・PNG・PDFの1ページ目）を読み込みます。用紙サイズは画像の縦横比から自動で決まります。 |
| ② CSV | 表彰者リストのCSVを読み込みます（複数ファイル・フォルダ可、UTF-8／Shift_JIS）。1行が賞状1枚です。 |
| ③ 項目 | 台紙に足りない文字を追加します。**差込**はCSVの値が入る項目（氏名・所属・順位など）、**印字**は全員に同じ文字を刷る項目（第◯回の数字、日付の数字など）です。 |
| ④ 位置合わせ | プレビュー上でドラッグするか、数値と ▲▼◀▶ で台紙の空欄に合わせます。 |
| ⑤ 用紙・出力 | 用紙と刷り方を選んでPDFを作成します。最初は「テスト1枚」で位置を確かめてください。 |
| ⑥ 保存 | 台紙・項目・位置・用紙をまとめて名前を付けて保存します。 |

### 文字の書き方

`{氏名}` のように `{ }` で囲んだ部分がCSVの値に置き換わります。囲まない文字はそのまま全員に刷られます。

| タグ | 内容 |
|---|---|
| `{氏名}` `{ふりがな}` `{所属}` `{都道府県}` | 選手の情報 |
| `{クラス}` `{種目}` `{分類}` | 区分の情報 |
| `{部門}` | 種目があれば種目、空欄なら分類（例：個人総合） |
| `{順位}` `{順位漢}` | 順位（`1` / `一`） |
| `{得点}` `{ゼッケン}` `{性別}` `{学年}` | その他 |

CSVの列名は自動で判定します。違う場合は ② の「列の対応」で選び直せます。列名をそのまま `{年齢/学年}` のように書くこともできます。

### 刷り方

- **台紙に刷る（追加した項目だけ）**：印刷済みの賞状用紙に、名前や数字だけを刷り込みます。
- **白紙に刷る（台紙の画像ごと）**：スキャン画像も一緒に出力します。台紙を切らしたときや見本用です。

プリンタの給紙で全体がずれる場合は、④ の「全体の印刷位置補正」でまとめて動かします。

## 保存について

- 設定は、使っているパソコンのブラウザ内（IndexedDB）に保存されます。台紙の画像も含みます。
- 別のパソコンや別の担当者と共有するときは、⑥ の「書き出す（JSON）」で設定ファイルを渡し、相手側で「読み込む（JSON）」をします。
- 名簿のCSVはどこにも保存しません。毎回読み込んでください。
- ブラウザの閲覧データ（サイトデータ）を消すと、保存した設定も消えます。大事な版面はJSONに書き出して残してください。

## GitHub Pages での公開手順

1. GitHubで新しいリポジトリを作ります（例：`shojo-maker`）。
2. このフォルダの中身をすべてリポジトリの直下にアップロードします。`.nojekyll` も含めてください。
   ```
   index.html
   favicon.svg
   .nojekyll
   README.md
   css/style.css
   js/app.js
   sample/sample_入賞者.csv
   ```
3. リポジトリの **Settings → Pages** を開き、**Source** を「Deploy from a branch」、**Branch** を `main` / `/ (root)` にして **Save** します。
4. 1〜2分後、`https://<ユーザー名または組織名>.github.io/shojo-maker/` で開けるようになります。

コマンドで行う場合：

```bash
cd shojo-maker
git init
git add .
git commit -m "賞状メーカー 初版"
git branch -M main
git remote add origin https://github.com/<組織名>/shojo-maker.git
git push -u origin main
```

### 注意

- **台紙のスキャン画像や表彰者のCSVをリポジトリに入れないでください。** 公開リポジトリのGitHub Pagesは誰でも閲覧できます。特に公印入りの台紙画像は外部に出さないようにしてください。動作確認には `sample/` の架空データを使います。
- `index.html` に `noindex` を入れてあるため、検索エンジンには載りません（URLを知っていれば開けます）。
- PDF作成（jsPDF）、PDF台紙の読み込み（pdf.js）、賞状用の書体（Google Fonts）はCDNから読み込みます。インターネットに接続した状態で使ってください。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の構成 |
| `css/style.css` | 見た目（CRAFTCODE管理画面と同じBootstrap 5系の配色） |
| `js/app.js` | CSV読み込み、描画、PDF作成、保存 |
| `favicon.svg` | タブのアイコン |
| `sample/sample_入賞者.csv` | 動作確認用の架空データ |

## 動作環境

Chrome・Edge の最新版を推奨します（Safari・Firefoxでも動作します）。フォルダごとの読み込みはChrome・Edgeのみ対応です。
